空気の小さな塊にニュートンの運動方程式を当てはめるだけで、「音は約 343 m/s で、形を崩さずに伝わる」ことを導く短い教科書です。数式の途中式を省かず、具体的な数値例とアニメーション(GIF)で、微分や2回微分が何を意味しているのかまで説明しています。

| 章 | 内容 |
